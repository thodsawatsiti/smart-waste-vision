รายละเอียด Data Flow

Entity ทิศทาง Data Flow รายละเอียด
User → เข้า รูปภาพขยะ ผู้ใช้ถ่ายรูปขยะผ่าน React Native แล้วส่งไป API (HTTP POST)
User ← ออก ผลจำแนก + แนะนำถัง ส่งกลับ: ประเภทขยะ, confidence, ถังที่ควรทิ้ง (JSON)
Admin → เข้า จัดการระบบ / Retrain เพิ่ม dataset, สั่ง retrain โมเดล, ตั้งค่า config
Admin ← ออก สถิติ / รายงาน ดู confusion matrix, accuracy, สถิติขยะแต่ละจุด
PostgreSQL → เก็บ บันทึกผลทำนาย เก็บ class, confidence, timestamp, ตำแหน่งจุดทิ้ง
PostgreSQL ← ดึง ประวัติ / สถิติ ดึงข้อมูลมาแสดง dashboard, วิเคราะห์ bias
Kaggle → เข้า Dataset รูปภาพขยะ Garbage Classification V2: 19,759 รูป, 10 classes
Docker → deploy Container Deployment บรรจุ FastAPI + YOLOv8 + PostgreSQL เป็น container

Label (Classification vs Detection)

Classification does not require manual bounding box annotation

Classification (Used) ✅

Label = folder name

Put image in plastic/ folder
= Model learns "this is plastic"

No bounding box needed
No annotation tool needed

Easy & Fast

Detection (Not used) ❌

Label = .txt file with coordinates

0 0.5 0.5 0.9 0.9
= class x y width height

Must draw bounding box per image
Requires annotation tool (LabelImg)

Time-consuming
